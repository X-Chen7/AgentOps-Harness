# SKILL.md 标准模板

新增技能时按此模板编写。`SKILL.md` 是技能唯一权威，所有可执行信息必须放在这里。

## Frontmatter

```yaml
---
name: skill-name
description: 用一句话说明技能做什么，以及什么场景会触发使用。
---
```

## 正文结构

```markdown
# 技能定位

一句话说明技能解决什么问题。

## 触发条件

- 列出触发该技能的具体任务场景。

## 输入上下文

- 列出执行前需要读取的文件和上下文。

## 执行步骤

1. 用可执行的顺序列出步骤。
2. 每一步要具体到能直接执行。

## 输出格式

```text
固定字段：
字段2：
```

## 停止条件

- 列出不能继续执行的情况。

## 验证要求

说明执行后如何验证，以及无法验证时怎么办。
```

## 编写要求

- 使用祈使句，直接告诉执行者做什么。
- 保持自包含，不依赖外部 spec 草案。
- 步骤不超过 500 行。
- 输出格式必须固定，方便后续人和智能体统一消费。
