# 项目知识（wiki）

本目录用于存放项目事实、API、数据模型、前端对接和设计说明。

当前 AgentOps-Harness 演示仓库以治理框架为主，不承载特定业务知识。初始化到具体项目后，再按 `.harness/rules/documentation-change-rule.md` 和 `.harness/skills/db-schema-sync/SKILL.md` 补充：

- `business-domain.md`：业务域模型
- `api-contract.md`：接口契约
- `data-model.md`：数据模型
- `frontend-integration.md`：前端对接说明
- `runtime-and-deployment.md`：运行与部署
- `feature-design/`：复杂功能设计说明
